Horren voor je klanten, met je eigen code

Voor kozijnspecialisten, schilders en andere vakmensen die toch al bij het raam staan. Je klant bestelt gewoon op deze site. Met jouw code krijgt hij {{partnercode.korting}}% korting, en wij zien dat hij via jou komt.

Zo werkt het

Meet bij je klant

Per raam twee maten: de breedte en de hoogte van de opening waar het raam in dichtvalt. Heb je net folie of verf op het kozijn gezet? Meet dan daarna.

Geef je code door

Zet de horren in de winkelmand, op je eigen telefoon of op die van je klant, en stuur ze door met "Bestelling bewaren of doorsturen": je code zit er dan vanzelf in. Of geef je klant alleen je code.

Je klant bestelt, wij doen de rest

Hij betaalt met iDEAL en krijgt {{partnercode.korting}}% korting. De horren worden op maat gemaakt en bij hem thuisbezorgd. Erin klikken doet hij zelf, zonder gereedschap.

Waarom vakmensen het doen

  • Geen voorraad en geen tweede rit. Je komt niet terug om horren te plaatsen.
  • Geen geld voorschieten. Je klant betaalt zelf, vooraf.
  • Je klant krijgt korting, en horren in de kleur van zijn kozijn. Ook als je het kozijn net een andere kleur hebt gegeven.
  • Het kozijn blijft heel. Geen boren, geen schroeven, geen tape.
  • Je klant is goed geholpen. Met onze pasgarantie, en met ons als aanspreekpunt voor de levering.

Wat verdien je eraan?

Voor elke bestelling met jouw code krijg je een vergoeding. Hoeveel, spreken we met je af als je een code aanvraagt.

Je code op je telefoon zetten

Doe dit één keer. Een winkelmand die je daarna doorstuurt, heeft je code erin, en je klant ziet zijn korting meteen bij het afrekenen.

Nog geen code? Stuur ons een WhatsApp of mail naar {{winkel.email}}. Dan maken we er een voor je.

Heb je een code van je vakman?

Vul hem in bij het afrekenen, of open de link die je van hem kreeg: dan staat hij er al. Je krijgt {{partnercode.korting}}% korting op je horren.

Verder bestel je zoals iedereen: de maten invullen, de kleur kiezen en betalen met iDEAL. Past er toch een hor niet, dan maken we een nieuwe.
